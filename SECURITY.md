# Relatar problemas de segurança

Para um problema que exponha dados ou permita executar ações indevidas, use o canal privado de reporte de vulnerabilidades na aba **Security** do GitHub, quando disponível. Não publique uma prova com tokens, caminhos pessoais ou dados de terceiros em uma issue aberta.

O MiniDeck executa atalhos, texto e programas definidos no perfil. Revise perfis JSON recebidos de outras pessoas antes de importá-los. O aplicativo não exige administrador, instala serviço ou atualiza firmware.

O projeto não promete um prazo de correção ou uma auditoria de segurança. Relatórios comuns de funcionamento podem usar as issues.
